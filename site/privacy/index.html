Card Dashboard privacy policy

Last updated: 2026-10-07

Who uses this app

Card Dashboard is a personal tool with a single user. Its owner built it, operates it and is the only person who uses it. It is not offered to the public, and nobody else's account is connected to it.

Google data it reads

With the owner's authorization, the app reads the card-notification emails that the owner's banks send to the owner's Gmail account. It extracts the date, amount, merchant and card number suffix of each transaction. It does not read any other email content for any other purpose.

Google data it writes

The app writes the extracted transactions to a Google Sheet that the owner owns, and reads that Sheet back to show the owner's dashboard. It writes to no other Google file or service.

LINE messages

The app runs a LINE bot that accepts messages from the owner only. Messages from any other LINE user are ignored and not stored. The owner's messages are used to add or undo entries in the owner's Sheet.

Gemini API

To parse a free-text entry and to suggest a category for a transaction, the app sends the relevant text (for example a merchant name or a short message from the owner) to Google's Gemini API.

Sharing

No data is sold, and no data is shared with third parties. Data leaves the owner's Google account only in the requests that the features above require: to the Gemini API for parsing and classification, and to LINE to reply to the owner's own messages.

Storage and deletion

All records stay in the owner's own Google Sheet and Google account. The owner can delete them at any time, and can revoke the app's access from the Google account's security settings.
